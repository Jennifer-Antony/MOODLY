# Moodly 💗 — Your Personal Mood Diary

Moodly is a simple mood-tracking web application that helps users record their daily emotions, add personal notes, and reflect on their feelings over time.

## ✨ Features

- **Daily Mood Tracking:** Record your mood using options such as Happy, Calm, Okay, Sad, and Stressed.
- **Personal Notes:** Add notes about your day or what you are feeling.
- **Mood History:** View previously saved mood entries with dates and times.
- **Edit Entries:** Update a mood or note whenever needed.
- **Delete Entries:** Remove entries you no longer want to keep.
- **Database Storage:** Store mood entries in MongoDB.

## 🛠️ Technologies Used

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB with Mongoose
- **Development Tool:** Vite

## 📁 Project Structure

- `client/` — Frontend application
- `server/` — Backend API and database integration
- `server/models/` — MongoDB data model

## 🚀 Getting Started

1. Install Node.js.
2. Install frontend dependencies inside `client/` using `npm install`.
3. Install backend dependencies inside `server/` using `npm install`.
4. Configure your MongoDB connection string in `server/.env`.
5. Start the backend server using `node server.js`.
6. Start the frontend development server using `npm run dev`.

Keep database credentials in your local `.env` file and never upload them to GitHub.

## 🎯 Project Goal

Moodly aims to provide a simple, accessible, and user-friendly space for tracking daily emotions and maintaining a personal mood diary.
